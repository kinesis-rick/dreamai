SIMULATION & PHYSICS ENGINE:
1. Dynamic Quarter-Mile:
   ET = 5.825 * ((weightKg * 2.20462) / HP)**(1/3) * (1.0 - ((lateralG - 0.90) * 0.12) - dtBonus)
   (dtBonus: AWD = 0.04, RWD = 0.00, FWD = -0.03).
   TrapSpeedKmh = (234 * (HP / (weightKg * 2.20462))**(1/3)) * 1.60934.
2. Normalized Race Scoring:
   Because acceleration is lower-is-better, normalize each stat to a 0-100 scale:
   - AccelScore = Math.max(0, Math.min(100, (12.0 - accelZeroHundred) * 10))
   - SpeedScore = Math.max(0, Math.min(100, (topSpeedKmh / 400) * 100))
   - GripScore = Math.max(0, Math.min(100, ((lateralG - 0.70) / 0.60) * 100))
   RaceScore = (W_accel * AccelScore) + (W_speed * SpeedScore) + (W_grip * GripScore) + (styleRating * 0.05).
   Highest RaceScore takes the heat.
